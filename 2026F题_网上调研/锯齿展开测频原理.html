锯齿展开测频：一条链路的完整原理

为什么 K230 发 $RAMP → F407 出锯齿 → 屏幕把正弦"拉直" → 一帧数周期就能测出频率

一句话本质

示波器的 X-Y 模式是一个二维绘图机：X 轴接输入正弦，Y 轴接锯齿斜坡。斜坡电压随时间匀速爬升，屏幕上的光点就沿着 Y 方向匀速移动——相当于把"时间"画成了屏幕上的 Y 坐标。于是输入正弦在屏幕上被展开成一条波形，你只需要数这条波形在屏幕上出现了几个周期，就知道频率。

通俗类比：把正弦波放在传送带上匀速拉过（传送带速度 = 锯齿斜率），对着传送带拍一张照片，数照片里有几个完整的波峰。一帧照片 = 一个斜坡周期，数出来的周期数 N 直接换算频率。

第 0 步：为什么 X-Y 模式下正常显示的是李萨如图

正常模式：X=sin(fx·t)、Y=sin(fy·t+φ)。当 fy/fx = 1:1 → 椭圆/圆；fy/fx=2:1 → ∞ 形。图形形状编码了频率比与相位差。

第 1 步：换 Y 源 —— 锯齿把时间轴"画"到屏幕上

锯齿斜坡 V_ramp(t) = A·(t mod T_ramp)/T_ramp，周期 T_ramp = 1ms（1kHz）。

把 Y 轴从正弦换成锯齿后，屏幕上每个 Y 高度都对应一个确定的斜坡相位 u = (t mod T_ramp)/T_ramp ∈ [0,1)——也就是一个确定的时刻。屏幕由"X-Y 李萨如图"变成"把时间轴按 Y 方向展开的波形图"。

第 2 步：核心公式 N = fx × T_ramp

X 通道输入： x(t) = A·sin(2π·fx·t) 斜坡相位： u = (t mod T_ramp) / T_ramp 把 t 换成 u：t = u·T_ramp（忽略模余，整周期对齐） x(u) = A·sin(2π·fx·T_ramp·u) = A·sin(2π·N·u) 其中 N = fx·T_ramp ← 斜坡一个周期内的输入正弦周期数
fxT_ramp=1ms 时 N屏幕上看到的
1 kHz1.01 个完整正弦周期
10 kHz1010 个周期
50 kHz5050 个周期
100 kHz100100 个周期（超出可接受上限→换更快斜坡）

所以：测出屏幕上波形有几个周期 N，就测出了频率 fx = N / T_ramp = N × 1000 Hz。整条链路的终点就是一个"数周期"问题。

第 3 步：图像侧怎么数周期（三步）

  • ① 行质心：对每个屏幕行（= 一个斜坡相位 u），把该行所有黄色轨迹像素求 X 均值 → 得到约 80~380 个离散采样点 (u_i, x_i)。轨迹是细线，每行就一个点，质心即采样。
  • ② 整数周期 DFT 粗估：对 k=1..60 扫离散正弦相关功率 P(k)=(Σx·cos(2πk u))²+(Σx·sin(2πk u))²，功率最大的整数 k = 周期数粗估（MicroPython 无 numpy FFT，纯 Python 内积，毫秒级）。
  • ③ 最小二乘细化：在粗估 ±1 周期内用黄金分割扫 N，每次拟合 4 元模型 x̂ = a·sin(2πNu) + b·cos(2πNu) + c + d·u（sin/cos 吸收幅度与相位，直流项吸收偏移，线性项吸收斜坡非线性/亮度漂移），取残差最小的小数 N。输出质量 quality = 1 − rms/半摆幅。

若实机估频命中率不足，代码已保留 RAMP_LOCAL_SWEEP_RANGE_GRID=12 常量——估频后在其邻域 ±1.2kHz 细扫确认，可兜住 0.05 周期以上的残余误差。

为什么必须用 100Hz 整数倍周期

题目频率步进 100Hz → 任意 fx 都是 100Hz 的整数倍。T_ramp 取 1ms（=10 个 100Hz 周期）后，每个斜坡起点，输入正弦恰好回到同一相位。示波器余晖把多帧轨迹叠加时不糊（所有帧波形重合），与 CdyWork/2026F-lissajous-controller 作者"10ms 斜坡=100Hz 整数倍"同源结论一致。若 T 不是 100Hz 整数倍，叠加会产生移动重影。
